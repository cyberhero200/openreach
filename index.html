Google sign-in for the site owner

Needed once so people can sign in and send through Gmail. Best: paste it into GOOGLE_CLIENT_ID at the top of the code so it works for everyone. This field only sets it for this browser.

How to get a Client ID (free, about 5 minutes)
  1. Open console.cloud.google.com and create a project.
  2. APIs & Services → Library: enable Gmail API and Google Drive API.
  3. Google Auth Platform → Branding: app name, your email. Audience: External. Add yourself (and friends, up to 100) as test users.
  4. Data access → add scopes gmail.send and drive.appdata.
  5. Clients → Create client → Web application. Authorized JavaScript origins: your site URL, e.g. https://your-site.netlify.app.
  6. Copy the Client ID here, or into the code.
